9 Week 9: Earth System Dynamics

In the first part of this tutorial, you will examine how dynamic coupling among climate system components shapes the response of global mean surface temperature to anthropogenic CO2 emissions between 1800 and 2024. In the second part, you will calculate feedback factors using a carbon pulse that initially doubles atmospheric CO2. In both parts, you will assess each component’s influence by comparing simulations with its dynamic coupling enabled and disabled.

9.2 Feedback Analysis

In this second section, we will calculate the feedback factors and system gains for each component. Unlike the experiments above, we use a reference simulation in which only the atmosphere and ocean are dynamically coupled. We then quantify the feedback associated with each additional component by enabling its dynamic coupling.

The atmosphere and ocean remain dynamically coupled in all experiments because most other components interact with the atmosphere through the ocean, and holding ocean temperatures fixed would make the ocean an infinite heat sink. Let us begin by recalling the definition of the feedback factor presented by Roe (2009):

\[f_i = 1 - \frac{\Delta T_0}{\Delta T_i} \]

Where \(\Delta T_0\) is the response in GMST to a sustained forcing of the reference system, and \(\Delta T_i\) is the response when component \(i\) is dynamically coupled. What exactly does \(f\) tell us? Each passage through the feedback loop multiplies the preceding temperature contribution by \(f\):

\[ \Delta T = \Delta T_0 + f\Delta T_0 + f^2\Delta T_0 + f^3\Delta T_0 + \cdots \]

This can be rewritten as:

\[ \Delta T = \Delta T_0 + f \Delta T \]

The feedback factor therefore tells us what fraction of the total warming is attributable to feedbacks. If the response is 3K and \(f = 0.1\) then 10% of the warming (0.3K) is due to feedbacks. The larger \(f\), the stronger the feedback, the larger the gain in temperature. The feedback factor and system gain are related as follows:

\[ \frac{\Delta T}{\Delta T_0} = \frac{1}{1-f} = G \]

The gain factor tells us by what factor feedbacks amplify or reduce the reference response. If the reference response is 1.5 K and \(G = 2\), then the total response is 3 K. To summarize, the feedback factor tells us what fraction of the total warming is attributable to feedbacks, while the gain factor tells us by what factor feedbacks amplify or reduce the reference response. Reproduce the figure below for values of \(f\) ranging from -0.8 to 0.8.

par(mar = c(6, 6, 1, 1))

f <- seq(-0.8, 0.8, by = 0.01)
G <- 1 / (1 - f)
plot(
  x = f, y = G, type = "l", col = "blue",
  xlab = "Feedback factor f (-)",
  ylab = "System Gain G (-)"
)
abline(v = 0, lty = 2)
abline(h = 1, lty = 2)
grid()

## [1] 516.8463
doubling_CO2 <- function(time) {
  C_atm_initial <- 516.8463 # Initial atmospheric carbon (PgC)
  start_year <- 0

  if (time >= start_year && time < start_year + 1) {
    C_atm_initial / (365.25 * 86400) # PgC/s
  } else {
    0
  }
}

9.2.10 Feedback factors

Read in the results from each experiment.

# Reference GMST
output <- readRDS("output_W09_config_01.rds")
T_1800 <- tail(output$T_atm_global, 1)

# Feedback results
ref <- readRDS("output_W09_feedback_ref.rds")
all <- readRDS("output_W09_feedback_all.rds")
sic <- readRDS("output_W09_feedback_sic.rds")
ice <- readRDS("output_W09_feedback_ice.rds")
all_but_carbon <- readRDS("output_W09_feedback_all_but_carbon.rds")
carbon <- readRDS("output_W09_feedback_carbon.rds")
AirSeaCarbon <- readRDS("output_W09_feedback_AirSeaCarbon.rds")
npzd <- readRDS("output_W09_feedback_npzd.rds")
lnd <- readRDS("output_W09_feedback_lnd.rds")

Calculate the GMST change for each experiment:

dT_ref <- tail(ref$T_atm_global, 1) - T_1800
dT_all <- tail(all$T_atm_global, 1) - T_1800
dT_sic <- tail(sic$T_atm_global, 1) - T_1800
dT_ice <- tail(ice$T_atm_global, 1) - T_1800
dT_all_but_carbon <- tail(all_but_carbon$T_atm_global, 1) - T_1800
dT_carbon <- tail(carbon$T_atm_global, 1) - T_1800
dT_AirSeaCarbon <- tail(AirSeaCarbon$T_atm_global, 1) - T_1800
dT_npzd <- tail(npzd$T_atm_global, 1) - T_1800
dT_lnd <- tail(lnd$T_atm_global, 1) - T_1800

Calculate the feedback parameter for each experiment.

f_all <- 1 - dT_ref / dT_all
f_sic <- 1 - dT_ref / dT_sic
f_ice <- 1 - dT_ref / dT_ice
f_all_but_carbon <- 1 - dT_ref / dT_all_but_carbon
f_carbon <- 1 - dT_ref / dT_carbon
f_AirSeaCarbon <- 1 - dT_ref / dT_AirSeaCarbon
f_npzd <- 1 - dT_ref / dT_npzd
f_lnd <- 1 - dT_ref / dT_lnd

feedback <- data.frame(
  f_all,
  f_sic,
  f_ice,
  f_all_but_carbon,
  f_carbon,
  f_AirSeaCarbon,
  f_npzd,
  f_lnd
)

colnames(feedback) <- c("All", "Sea ice", "Ice sheet", "All-but-carbon", "Carbon", "Air-sea carbon", "NPZD", "Land")

Gain <- 1 / (1 - feedback)

Plot the results.

par(mfrow = c(2, 1), mar = c(7, 5, 1, 1))
barplot(unlist(feedback), col = "steelblue", las = 2, ylab = "Feeback factor f(-)")
box()

barplot(unlist(Gain), col = "steelblue", las = 2, ylab = "System Gain G (-)")
box()
