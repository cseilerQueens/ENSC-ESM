11 Week 11: Paleoclimatic Simulations

11.1 Saltzman and Maasch (1990)

Let us begin our discussion with a very simple first-order global model of late Cenozoic climatic change developed Saltzman and Maasch (1990) (referred to as SM1990 hereafter). The model has three prognostic variables and one external forcing variable:

\[ \frac{dX}{dt} = -X - Y - v Z - u R(t)\] \[ \frac{dY}{dt} = - p Z + r Y - s Y^2 - Y^3\]

\[ \frac{dZ}{dt} = -q X - q Z \]

where \(X\) is global ice mass, \(Y\) is atmospheric CO\(_2\) concentration, \(Z\) is deep ocean temperature, and \(R(t)\) is insolation anomalies (all non-dimensional). The parameters \(p, q, r, s, u, v\) all have positive values. Let’s start with the insolation anomalies, which are the June-solstice insolation at 65 Degrees N. Run the code below to show the incoming solar radiation between the last half-million years and today:

library(palinsol)

# June-solstice insolation at 65°N, sampled every 10 years
year <- seq(-500000, 0, by = 10)
latitude <- 65 * pi / 180

isl <- vapply(year, function(t_year) {
  Insol(orbit = ber78(t_year), long = pi / 2, lat = latitude)
}, numeric(1))

plot(
  year, isl,
  type = "l",
  main = "Daily mean insolation at the June solstice",
  xlab = "Years relative to 1950",
  ylab = expression("TOA insolation (" * W ~ m^{-2} * ")")
)
legend("topleft", "65°N", bty = "n")
abline(h = 480.05, col = "grey")

Quiz Question 1: What is the approximate range of incoming solar radiation during this period?

The SM1990 model uses dimensionless variables. To make the insolation forcing dimensionless, we subtract its mean and divide the result by three times its standard deviation:

# Express insolation anomalies in units of three standard deviations
isl_mean <- mean(isl)
isl_sd <- sd(isl)
R <- (isl - isl_mean) / (3 * isl_sd)

Let us now integrate the model forward in time using the Euler integration method:

# Model parameters
p <- 1.0
q <- 2.5
r <- 1.3
s <- 0.6
u <- 0.5
v <- 0.2

# Time in kyr for plotting. The model's time unit is 10 kyr.
times <- year / 1000
dt_model <- (times[2] - times[1]) / 10
n <- length(times)

# R[1] is the forcing at -500 kyr.
if (length(R) != n || any(!is.finite(R))) {
  stop("R must contain one finite forcing value per time point.")
}

# Preallocate state vectors and set initial conditions
x <- y <- z <- numeric(n)
x[1] <- 0.6
y[1] <- -0.8
z[1] <- -0.2

# Forward Euler integration
for (i in seq_len(n - 1L)) {
  dx <- -x[i] - y[i] - v * z[i] - u * R[i]
  dy <- -p * z[i] + r * y[i] - s * y[i]^2 - y[i]^3
  dz <- -q * (x[i] + z[i])

  x[i + 1L] <- x[i] + dt_model * dx
  y[i + 1L] <- y[i] + dt_model * dy
  z[i + 1L] <- z[i] + dt_model * dz
}

df <- data.frame(time = times, R = R, x = x, y = y, z = z)

We can now plot the data:

par(mfrow = c(4, 1), mar = c(3,5,1,1))
# Plot

my.col <- palette.colors(n = 4, palette = "Okabe-Ito")

plot(x = df$time, y = df$R, type = "l", xlab = "Age (ka)", ylab = "Insolation (-)", col = my.col[1])
grid()

plot(x = df$time, y = df$x, type = "l", xlab = "Age (ka)", ylab = "Ice (-)", col = my.col[2], lwd = 2)
grid()

plot(x = df$time, y = df$y, type = "l", xlab = "Age (ka)", ylab = "CO2 (-)", col = my.col[3], lwd = 2)
grid()

plot(x = df$time, y = df$z, type = "l", xlab = "Age (ka)", ylab = "Ocean Temp (-)", col = my.col[4], lwd = 2)
grid()

For better comparison, let us now overlay \(X\), \(Y\), and \(Z\) in a single plot.

11.2 QUEST

In this part of the tutorial, you will analyze QUEST simulations of the past 400,000 years. The atmosphere, ocean, and sea ice are dynamically coupled. Atmospheric CO\(_2\) concentrations are prescribed from ice-core records, and ice-sheet mass is prescribed from estimates of past sea-level change. The NPZD, land module, and air-sea carbon exchanges, are disabled to reduce computation time. I have completed the simulation for you because it takes about seven hours to complete. Let us begin by reading in the model output file.

library(quest)
output <- readRDS("/global/teaching-project/sg5112000/shared_files/W11_output_paleo_prescr_ice.rds")

# Set the path to the configuration files:
config.path <- "/global/teaching-project/sg5112000/shared_files/config"

# Load the configuration files:
config <- config_load(path = config.path)

11.2.4 Relationships

Let us now explore how the variables relate to one another by plotting them in pairs. We will begin with the strength of the thermohaline circulation and surface ocean density contrasts:

d <- output[output$time >= -350000 &
            output$time <= -1000, ]

# Sample every 1,000 years.
d <- d[seq(1, nrow(d), by = 1000), ]

delta_rho <- d$rho_SH - d$rho_SL
plot(delta_rho, d$Q / 1e6, type = "l", col = "blue",
     xlab = "High-lat minus low-lat \n ocean surface water density (kg/m3)",
     ylab = "Thermohaline Circulation (Sv)")
grid()

Quiz Question 13: Describe the relationship between ocean surface density contrast and the thermohaline circulation

Let us now investigte how sensitive the thermohaline circulation is to warming.

d <- output[output$time >= -350000 &
            output$time <= -1000, ]

# Sample every 1,000 years.
d <- d[seq(1, nrow(d), by = 1000), ]

x <- d$T_atm_global
y <- d$Q/1e6
plot(x, y, pch = 20, col = "blue",
     xlab = "GMST (K)",
     ylab = "Thermohaline Circulation (Sv)")
fit <- lm(y ~ x)
abline(fit, col = "red", lwd = 2)

grid()
