10 Week 10: Future Climate Simulations

In this tutorial you will make long-term climate change projections for the next 10,000 years using the SSP5-8.5 emission scenario. Using a range of control experiments, you will further assess how each component contributes to future warming. Finally, you will produce phase portraits, perturbing fractional sea ice cover and atmospheric carbon. All simulations start from the spun-up state produced during last week’s tutorial using the fully dynamically coupled model configuration. We begin by defining a function that adds anthropogenic emissions consistent with SSP5-8.5.

10.1 Emissions (SSP5-8.5)

The function below reads in a text file that gives the emissions in Pg per year, converts the unit to Pg per second and then assigns the emissions to the correct years.

ssp585 <- function(time) {
  data <- read.table("/global/teaching-project/sg5112000/shared_files/config/data/future_emissions.txt", head = TRUE)
  emissions <- data$SSP5_8.5
  emissions <- emissions / (365.25 * 86400)
  if (time >= 1750 && time < 2500) {
    emissions[time - 1749]
  } else {
    0
  }
}

10.2 Attribution

10.2.1 Sea Ice

We will now quantify how changes in sea ice affect warming. To do this, we will disable the sea ice module, keeping sea ice present while holding its spatial extent, volume, accumulation, and ablation constant at their equilibrium values for the year 1750. Disabling a module prevents QUEST from updating the state variables calculated by that module, leaving them fixed at their initial values. Any diagnostic variables or fluxes normally calculated by the module must be specified explicitly. One example is the fractional area covered by sea ice, A_sic. The results will be saved in a .rds file for later analysis.

# Read default configuration
config <- config_load(path = config.path)

# Get the spun-up state
state_eq <- source("/global/teaching-project/sg5112000/shared_files/config_init_W09_config_01.R")$value
config$initial_values <- state_eq

# Get the equilibrium value
output <- readRDS("/global/teaching-project/sg5112000/shared_files/output_W09_config_01.rds")
n <- nrow(output) # last time step
A_sic <- output$A_sic[n] # last time step value
config$prescribed_values$A_sic <- A_sic

# flags
# Set the flags to what we want
config$flags$run_AirSeaCarbon <- TRUE
config$flags$run_atmosphere <- TRUE
config$flags$run_ocean <- TRUE
config$flags$run_npzd <- TRUE
config$flags$run_land <- TRUE
config$flags$run_sic <- FALSE
config$flags$run_icesheets <- TRUE
config$flags$anthropogenic_emissions <- TRUE
config$flags$prescribed_CO2 <- FALSE
config$flags$prescribed_seaice <- FALSE
config$flags$diagnose_carbonates <- FALSE

# Assign emissions

10.3 Phase Portraits

Let us now investigate sea ice dynamics in more detail. Can QUEST reach different sea ice equilibria depending on the initial atmospheric CO\(_2\) concentration and sea ice extent, even when the total amount of carbon is the same? To test this, we perturb both atmospheric carbon content and sea ice extent. Adding carbon would change the system’s total carbon inventory, which can itself shift the equilibrium. We therefore redistribute carbon among reservoirs. Any carbon added to the atmosphere is removed from other reservoirs, and any carbon removed from the atmosphere is added to them. We combine low, medium, and high initial atmospheric carbon contents with low, medium, and high initial sea ice extents. We then run the model from each of the initial conditions until it reaches equilibrium. Will a run that starts with high atmospheric CO\(_2\) and little sea ice settle into a warm equilibrium, or will the ocean take up enough CO\(_2\) for the climate to cool and sea ice to regrow? Let’s find out!

Run the code below to investigate how different initial conditions affect the equilibrium. The code takes a few minutes to complete as each trajectory runs for 4000 years.

# Read default configuration
config <- config_load(path = config.path)

# Get the spun-up state
state_eq <- source("/global/teaching-project/sg5112000/shared_files/config_init_W09_config_01.R")$value
config$initial_values <- state_eq

# flags
# Set the flags to what we want
config$flags$run_AirSeaCarbon <- TRUE
config$flags$run_atmosphere <- TRUE
config$flags$run_ocean <- TRUE
config$flags$run_npzd <- FALSE # turn off for speed
config$flags$run_land <- TRUE
config$flags$run_sic <- TRUE
config$flags$run_icesheets <- TRUE
config$flags$anthropogenic_emissions <- FALSE
config$flags$prescribed_CO2 <- FALSE
config$flags$prescribed_seaice <- FALSE
config$flags$diagnose_carbonates <- FALSE

phase_result <- eval_phase_edges(
  config = config,
  state_ref = state_eq,
  x_var = "A_sic",
  y_var = "C_atm",
  x_range = c(0, 1),
  y_range = c(500, 4000),
  times = seq(-4000, 0, by = 1),
  n_edge = 3,
  warnings_are_errors = FALSE
)

saveRDS(phase_result, "W10_phase_result.rds")

Plot the results.

data <- readRDS("W10_phase_result.rds")

plot(
  x = c(500, 4000), y = c(0, 1), col = NA,
  xlab = "Atmospheric Carbon (PgC)",
  ylab = "Fractional Sea Ice Area (-)"
)

n <- length(data$outputs)
last <- length(data$outputs[[1]]$C_atm)

my.col <- grDevices::hcl.colors(n, palette = "Dark 3")

for (i in 1:n) {
  x <- data$outputs[[i]]$C_atm
  y <- data$outputs[[i]]$A_sic
  lines(x, y, col = my.col[i])

  x1 <- data$outputs[[i]]$C_atm[1]
  y1 <- data$outputs[[i]]$A_sic[1]

  xn <- data$outputs[[i]]$C_atm[last]
  yn <- data$outputs[[i]]$A_sic[last]

  points(x = x1, y = y1, col = my.col[i], pch = 1)
  points(x = xn, y = yn, col = my.col[i], pch = 16)
}

legend("topright", pch = c(1, 16), c("Start", "End"), bty = "n", horiz = TRUE)
grid()
